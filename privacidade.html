Privacidade — NutriFit

Esta versão do NutriFit mantém no próprio aparelho os dados que você registra no aplicativo, como perfil, diário, prato e evolução. Esses dados são armazenados localmente pelo navegador.

O aplicativo não precisa enviar seus registros pessoais para um servidor para realizar os cálculos nutricionais desta versão.

Ao exportar ou compartilhar dados por uma ação escolhida por você, o conteúdo passa a seguir as regras do serviço para o qual você o enviar.

O banco nutricional principal é baseado na TACO e é usado para cálculos informativos. O NutriFit não substitui orientação de médico ou nutricionista.
